# Token Pet 데스크톱 위젯

화면 구석에 펫을 띄우는 Tauri 2 앱. `~/.claude/pet/state.json`을 감시해서 읽기만 하고, 먹이주기는 플러그인의 `pet.py feed --json`을 서브프로세스로 호출한다. 플러그인이 먼저 설치돼 있고 Claude Code 세션을 한 번 이상 시작했어야 한다(그때 `plugin_root`가 기록된다).

## 동작

- 접힌 상태 120×120: 스프라이트 + 코인. 턴이 끝나 코인이 들어오면 "+N" 말풍선 2초.
- 클릭하면 360×460으로 펼쳐진다: 이름/레벨/코인, 말풍선, 배고픔·기분 바, 먹이주기·꾸미기. 바는 파일이 안 바뀌어도 10초마다 플러그인과 같은 공식으로 줄어든다.
- 먹이주기는 코인이 50 미만이면 버튼이 꺼지고 `12/50` 처럼 부족분을 보여준다. 플러그인이 거절한 경우(낮잠, 가출 등)는 말풍선과 토스트에 이유가 뜬다.
- 펫이나 위젯 아무 곳이나 잡고 끌어서 옮긴다(버튼과 아이템 목록 제외). 접힌 위치는 기억해서 다음 실행 때 그 자리에 뜬다. 저장된 자리가 연결된 화면 밖이면 오른쪽 아래로 돌아간다.
- 펼치면 펫 기준 왼쪽 위로 커지되 화면 밖으로 나가지 않게 맞춘다. 접으면 원래 자리로 돌아간다. Esc·× 버튼·포커스 잃음으로 접힘.
- 애니메이션: 평소엔 통통 튀며 눈을 깜빡인다. 기분 좋으면 빠르게, 배고프면(20 미만) 느리고 칙칙하게, 야행성 형태는 낮에 눈 감고 z를 띄운다. 먹이는 점프와 하트, 구매·착용은 반짝이, 거절은 고개 흔들기, 레벨업은 큰 반짝이. 시스템 설정의 '동작 줄이기'를 켜면 전부 멈춘다.
- 펼친 창에서 펫을 누르면 쓰다듬는다. 기분 +8, 하루 5번까지.
- 막대 아래 한 줄에 진화 예감을 보여 준다. 다음 진화가 지금 기록으로 어떤 형태를 고를지와 그 이유.
- 머리말의 그래프 버튼은 최근 7일 기록 패널을 연다. 하루 번 코인 막대 그래프, 막대에 마우스를 올리면 그날의 출력 토큰과 먹이 횟수.
- 알림: 배고픔 20 미만, 배고픔 0, 6일째 굶김(다음 날 가출) 단계마다 macOS 알림을 한 번씩 보낸다. 먹이를 주면 다시 처음부터. 처음 한 번 macOS가 알림 허용을 묻는다.
- 꾸미기 버튼은 펫 아래로 상점 패널을 연다. `pet.py shop --json` 의 카탈로그로 목록을 그리고, 구매·착용·벗기는 각각 `buy`/`equip`/`unequip` 을 호출한다. 착용하면 위의 스프라이트가 바로 바뀐다. 코인이 모자라면 구매 버튼이 꺼지고 부족분이 표시된다.
- Dock 아이콘 없음, 항상 위, 모든 스페이스에 표시.

## 개발

```bash
curl -fsSL https://sh.rustup.rs | sh        # Rust (한 번)
cd app
npx @tauri-apps/cli@2 dev                   # 개발 실행
npx @tauri-apps/cli@2 build                 # src-tauri/target/release/bundle/{macos,dmg}/
```

프론트는 번들러 없이 `src/`의 바닐라 HTML/CSS/JS. `src/sprites.js`는 `docs/mockup.html`의 SVG에서 생성한 것이라 스프라이트를 바꾸려면 목업을 고치고 다시 뽑는다.

`PET_HOME` 환경변수로 상태 파일 위치를 바꿀 수 있다(플러그인과 동일).

## 설치 (배포본)

Releases에서 `.dmg`를 받아 응용 프로그램에 넣는다. 코드 서명이 없어서 처음엔 Finder에서 우클릭 → 열기.
