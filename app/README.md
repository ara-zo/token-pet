# Token Pet 데스크톱 위젯

화면 구석에 펫을 띄우는 Tauri 2 앱. `~/.claude/pet/state.json`을 감시해서 읽기만 하고, 먹이주기는 플러그인의 `pet.py feed --json`을 서브프로세스로 호출한다. 플러그인이 먼저 설치돼 있고 Claude Code 세션을 한 번 이상 시작했어야 한다(그때 `plugin_root`가 기록된다).

## 동작

- 접힌 상태 120×120: 스프라이트 + 코인. 턴이 끝나 코인이 들어오면 "+N" 말풍선 2초, 픽셀 동전이 말풍선에서 튀어나와 펫 뒤로 포물선을 그리며 코인 표시에 쏙 들어간다(번 만큼 1~6개, 펼친 창에서는 펫에서 머리말의 코인 표시로 날아감).
- 클릭하면 300×390으로 펼쳐진다: 이름/레벨/코인, 말풍선, 배고픔·기분 바, 먹이주기·꾸미기. 바는 파일이 안 바뀌어도 10초마다 플러그인과 같은 공식으로 줄어든다.
- 먹이주기는 코인이 50 미만이면 버튼이 꺼지고 `12/50` 처럼 부족분을 보여준다. 플러그인이 거절한 경우(낮잠, 가출 등)는 말풍선과 토스트에 이유가 뜬다.
- 펫이나 위젯 아무 곳이나 잡고 끌어서 옮긴다(버튼과 아이템 목록 제외). 접힌 위치는 기억해서 다음 실행 때 그 자리에 뜬다. 저장된 자리가 연결된 화면 밖이면 오른쪽 아래로 돌아간다.
- 펼치면 펫 기준 왼쪽 위로 커지되 화면 밖으로 나가지 않게 맞춘다. 접으면 원래 자리로 돌아간다. Esc·× 버튼·포커스 잃음으로 접힘.
- 애니메이션: 평소엔 통통 튀며 눈을 깜빡인다. 기분 좋으면 빠르게, 배고프면(20 미만) 느리고 칙칙하게, 야행성 형태는 낮에 눈 감고 z를 띄운다. 먹이는 점프와 하트, 구매·착용은 반짝이, 거절은 고개 흔들기, 레벨업은 큰 반짝이. 시스템 설정의 '동작 줄이기'를 켜면 전부 멈춘다.
- 펼친 창에서 펫을 누르면 쓰다듬는다. 기분 +8, 하루 5번까지.
- 막대 아래 한 줄에 진화 예감을 보여 준다. 다음 진화가 지금 기록으로 어떤 형태를 고를지와 그 이유.
- 종족: 모찌가 아닌 종족은 `src/species.js` 가 디자인 캔버스 '종족별 진화표'의 규칙으로 형태별 모습을 그린다. 모자·안경은 그 종족의 머리와 눈 위치로 옮기고, 옷(후드티)은 모찌 몸에 맞춰 그린 것이라 다른 종족에는 입히지 않는다.
- 종족 모션: 다람쥐 꼬리 반짝, 두더지 쏙 올라옴과 램프, 로봇 굴뚝 연기, 펭귄 뒤뚱과 별, 햄스터 귀 까딱과 꼬리 전구, 토끼 신호 파동·회로·세 번째 눈. 코인이 들어오면 고유 부위가 반응(결정 자람, 램프, 화로, 부리, 볼 뽈록).
- 형태 모션(펼친 창에서만): 불량배 건들건들(쓰다듬으면 손을 쳐냄), 보스는 미동 없이 선글라스만 번쩍, 번아웃 축 처짐과 연기, 야행성 낮잠 꾸벅, 재벌·인플루언서 반짝이, 탕진잼 코인 새어 나감. 배고프면 모든 모션이 절반 속도.
- 이벤트 모션: 진화하면 환전소 통지서가 날아와 펼쳐지고 번쩍, 갱생하면 비니를 던지고, 가출하면 화면 밖으로 걸어 나간다.
- 꾸미기의 도감 탭: 7종족. 쉬는 펫은 "데려오기", 등록된 종족은 "입양"(코인이 모자라면 꺼짐), 잠긴 종족은 실루엣, `???`, 소문 한 줄, 기척 점 세 개(정확한 조건과 숫자는 등록 후 공개). 펫을 바꿀 때는 진화·레벨업 연출을 띄우지 않는다.
- 머리말의 그래프 버튼은 최근 7일 기록 패널을 연다. 하루 번 코인 막대 그래프, 막대에 마우스를 올리면 그날의 출력 토큰과 먹이 횟수.
- 알림: 배고픔 20 미만, 배고픔 0, 6일째 굶김(다음 날 가출) 단계마다 macOS 알림을 한 번씩 보낸다. 먹이를 주면 다시 처음부터. 처음 한 번 macOS가 알림 허용을 묻는다.
- 배경: 펼친 창의 무대 배경은 `bg` 슬롯 아이템(`src/backgrounds.js`). 꾸미기 패널의 "배경" 탭에서 바꾼다. 형태로만 얻는 배경은 해금 조건이 보인다.
- PR 우편함 (`/pet pr on` 으로 켤 때만): 우편함의 「가져오는 곳」 탭에 GitHub 검색 조건(예: `is:pr org:*** is:open`)을 넣으면, 5분마다 `gh` 로 조건마다 검색해서 PR을 합쳐 보여 준다(조건당 50개까지, 같은 PR은 한 번만). `is:pr` 이 없으면 붙여 준다. 조건은 위젯에만 저장되고 처음엔 비어 있다(비어 있으면 우편함이 「가져오는 곳」 탭으로 열린다). `review-requested:@me` 가 든 조건으로 찾은 PR은 「내 리뷰」, 나머지는 「열린 PR」 칩이 붙는다. 안 읽은 PR이 있으면 접힌 창이 위로 46px 늘어나 펫 머리 위에 "안 읽은 PR이 N개 있어요!" 말풍선(내 리뷰가 있으면 분홍, 아니면 노랑)을 띄우고, 펫 옆에 편지가 꽂힌다. 새로 찾은 PR은 펫 말풍선과 깡총으로 알린다(macOS 알림은 없음). 켤 때나 조건을 새로 넣을 때 이미 있던 PR은 조용히 목록에만 들어간다. 항목을 누르면 브라우저로 열면서 읽음으로 표시하고, "모두 읽음"도 있다. 읽은 PR은 말풍선·편지·숫자에서 빠지고 목록에 흐리게 남는다(읽음 표시는 위젯에만 저장, GitHub는 그대로). 머지·종료 등으로 조건에서 빠지면 다음 확인 때 목록에서도 빠진다. 테스트·시연용으로 `PET_PR_FAKE=<검색 결과 JSON 파일>` 을 주고 띄우면 모든 조건에 GitHub 대신 그 파일을 읽는다. 토큰은 저장하지 않고 gh 의 로그인을 그대로 쓴다.
- 꾸미기 버튼은 펫 아래로 상점 패널을 연다. `pet.py shop --json` 의 카탈로그로 목록을 그리고, 구매·착용·벗기는 각각 `buy`/`equip`/`unequip` 을 호출한다. 착용하면 위의 스프라이트가 바로 바뀐다. 코인이 모자라면 구매 버튼이 꺼지고 부족분이 표시된다.
- Dock 아이콘 없음, 항상 위, 모든 스페이스에 표시.

## 개발

```bash
curl -fsSL https://sh.rustup.rs | sh        # Rust (한 번)
cd app
npx @tauri-apps/cli@2 dev                   # 개발 실행
npx @tauri-apps/cli@2 build                 # src-tauri/target/release/bundle/{macos,dmg}/
```

프론트는 번들러 없이 `src/`의 바닐라 HTML/CSS/JS. `src/sprites.js`는 `docs/mockup.html`의 SVG에서 생성한 것이라 스프라이트를 바꾸려면 목업을 고치고 다시 뽑는다.

`PET_HOME` 환경변수로 상태 파일 위치를 바꿀 수 있다(플러그인과 동일).

## 설치 (배포본)

플러그인이 알아서 한다. 첫 세션 시작 때 `Token-Pet-macos.zip`을 Releases에서 받아 `~/Applications`에 풀고 격리 속성을 지운 뒤 띄운다. 수동으로는 `/pet widget install`, 또는 Releases의 `.dmg`를 받아 응용 프로그램에 넣고 Finder에서 우클릭 → 열기(코드 서명이 없어서).

- **자동 실행**: 앱이 뜰 때 `state.json`의 `settings.widget`(기본 켬)에 맞춰 로그인 항목(`~/Library/LaunchAgents`)을 켜거나 끈다. `/pet widget off` 하면 다음 상태 변화 때 로그인 항목도 지운다. 개발 빌드(`tauri dev`)는 건드리지 않는다.
- **세션 시작**: 플러그인의 SessionStart 훅이 위젯이 설치돼 있으면 `open -g`로 띄운다. 이미 떠 있으면 아무 일도 없다.
- **릴리스**: `v*` 태그를 푸시하면 `.github/workflows/release-widget.yml`이 유니버설 빌드를 만들어 zip·dmg를 릴리스에 올린다.
