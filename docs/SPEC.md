# Token Pet — 컨셉 스펙 (1차)

Claude Code 토큰 사용량이 코인이 되는 다마고치. 코인으로 밥을 주고 꾸미며, 어떻게 키웠느냐에 따라 진화가 갈린다.
목업은 `mockup.html`(브라우저로 열기). 이 문서는 다른 Claude 세션에 그대로 붙여 넣어 이어서 작업하는 용도.

## 아키텍처 (서버·DB 없음, 전부 로컬)

```
token-pet/
  plugin/                      # Claude Code 플러그인
    .claude-plugin/plugin.json
    hooks/hooks.json           # Stop, SessionStart 훅
    scripts/collect.py         # Stop: 트랜스크립트 usage 읽어 코인 적립
    scripts/tick.py            # SessionStart: 경과시간 → 배고픔/기분 감소, 진화 판정, 불량배 삥뜯기
    scripts/pet.py             # /pet 커맨드 백엔드 (status, feed, shop, equip)
    commands/pet.md            # /pet 슬래시 커맨드
    statusline.sh              # 상태표시줄 한 줄
  app/                         # Tauri 데스크톱 앱 (HTML/CSS/JS + Rust 껍데기)
    src/                       # mockup.html의 위젯 그대로 사용
    src-tauri/                 # 투명·프레임리스·항상위 창, state.json watch
  README.md
```

- 단일 진실 공급원: `~/.claude/pet/state.json`
- 쓰기: 플러그인 훅/커맨드. 읽기: 데스크톱 앱(파일 watch). 둘은 서로 모름
- 쓰기는 임시파일 → rename 으로 atomic. 1차엔 SQLite 불필요
- 서버가 필요해지는 시점: 다기기 동기화, 랭킹, 남의 펫 구경 (2차 이후)

## state.json 스키마 (초안)

```json
{
  "version": 1,
  "name": "모찌",
  "level": 3,
  "xp": 1240,
  "coins": 1240,
  "hunger": 38,
  "mood": 72,
  "form": "base",
  "form_since": "2026-10-20T00:00:00+09:00",
  "items_owned": ["party_hat"],
  "equipped": { "head": "party_hat" },
  "last_fed_at": "2026-10-20T14:00:00+09:00",
  "last_tick_at": "2026-10-20T17:00:00+09:00",
  "daily_log": [
    { "date": "2026-10-20", "feeds": 2, "tokens_in": 88000, "tokens_out": 12400,
      "cache_hit_ratio": 0.61, "night_ratio": 0.2, "spent": 0, "earned": 312,
      "hunger_zero_hours": 0, "purchases": 0, "refusals": 0 }
  ],
  "flags": { "rehab_days": 0, "debt": 0 },
  "badges": []

```
- `daily_log`는 14일치만 유지
- `night_ratio`: 22:00~04:00 사이 사용한 출력 토큰 비율

## 경제

- 출력 1k 토큰 = 2코인, 하루 출력 300k 초과분은 1k = 0.3코인 (입력은 0, 캐시 적중률 50% 이상이면 +5% 보너스)
- 밥 50코인 → 배고픔 +40. 배고픔은 시간당 -5, 기분은 시간당 -2
- 레벨: xp = 누적 획득 코인. Lv.5 = 10,000, Lv.10 = 40,000 (조정 가능)
- 상점 아이템: 중절모 120, 선글라스 90, 후드티 200, 쿠션 150, 화분 80, 왕관(Lv.5 해금)

## 진화

### 1차 (Lv.5 도달 시, 지난 7일 기록으로 판정, 게이지는 숨김)
| 형태 | 조건 | 효과 |
|---|---|---|
| 모범생 | 하루 2회 이상 급식, 방치 6h 미만, 꾸미기 적당 | 코인 +10%, 배고픔 느리게 |
| 구두쇠 | 코인 1,000+ 보유, 구매 0회, 급식 최소 | 매일 잔액 1% 이자, 상점가 +30% |
| 올빼미 | 출력 토큰 60%+ 야간 | 밤 코인 2배, 낮엔 잠(급식 불가) |
| 사치쟁이 | 획득의 80%+ 꾸미기, 아이템 8+ | 기분 항상 높음, 매일 "신상 사줘" 요구 |
| 불량배 | 배고픔 0 누적 72h+ | 매일 잔액 10% 삥뜯음, 상점 봉쇄, 3일 연속 급식 시 갱생 |
| 가출 | 7일 방치 또는 불량배 +3일 | 코인 절반 들고 사라짐, 찾기 미션 |

우선순위: 가출 > 불량배 > 올빼미 > 구두쇠 > 사치쟁이 > 모범생(기본)

### 2차 (Lv.10, Lv.5~10 사이 기록)
| 1차 | 상승 | 타락 |
|---|---|---|
| 모범생 | 박사 (캐시 70%+): 코인 +20%, 절약 팁 | 번아웃 (출력 500k×5일): 이틀 코인 0, 하루 쉬면 회복 |
| 구두쇠 | 재벌 (10k 돌파 + 구매 1회+): 이자 3%, 전품목 해금, 금색 | 고리대금업자 (10k + 구매 0): 밥 외상, 이자로 잔액 깎임 |
| 올빼미 | 야행성 사냥꾼 (새벽 급식 3+): 밤 3배, 드롭 | 흡혈귀 (밤 90%+, 낮 0회): 낮 세션 시 5% 증발, 낮 3회로 복귀 |
| 사치쟁이 | 인플루언서 (아이템 15+, 거절 ≤3): 환급 10% | 탕진잼 (잔액 0 5일+, 거절 5+): 기분 급락, 아이템 랜덤 매각 |
| 불량배 | 갱생 → 1차 재판정 + 배지 | 조직 보스 (불량배로 Lv.10): 삥 25%, 상태표시줄 점거, "독립 선언" 리셋 |

타락 형태는 전부 복귀 조건이 있어 영구 패널티 없음.

## 스프라이트

64×64 픽셀 그리드 SVG(`shape-rendering: crispEdges`). 기본 몸 #FFB7C5, 눈 #23203A, 볼 #F38BA3.
형태별 차이는 mockup.html의 각 SVG 참고 (색 + 소품 + 조직보스는 덩치 1.4배).

## UI

- 접힌 상태: 120×120 투명, 스프라이트 96px + 코인 배지, 턴 끝나면 "+N" 말풍선 잠깐
- 펼친 위젯: 300×390 (#23203A), 이름/레벨/코인, 말풍선, 배고픔·기분 바, 밥 주기/꾸미기
- 패널: 밥/상점/옷장 탭, 아이템 그리드, 하단 오늘 획득·토큰·환율
- 상태표시줄: `경로 │ 모델 │ [스프라이트] 모찌 Lv.3 🪙1,240 +12 배고픔▓▓░░░ 기분▓▓▓▓░ … ctx 41% · $2.18`
- 팔레트: 바탕 #23203A / 카드 #2D2A4A / 텍스트 #F4F1FF / 보조 #A9A3C9 / 코인 #F5C451 / 배고픔 #F5A54A / 기분 #6FE3B3 / 경고 #F38BA3
- 폰트: Silkscreen(숫자·제목), IBM Plex Sans KR(본문), IBM Plex Mono(상태표시줄)

## 1차 범위

1. 플러그인: 훅 2개 + `/pet` 커맨드 + statusline → 터미널에서 밥 주기까지
2. state.json 스키마 + 진화 판정 로직
3. Tauri 앱: 접힌/펼친 상태만 (상점은 `/pet shop`으로 먼저)
