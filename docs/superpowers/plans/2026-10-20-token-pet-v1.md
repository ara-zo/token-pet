# Token Pet v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Claude Code 토큰 사용량을 코인으로 바꿔 먹이고 꾸미고 진화시키는 로컬 전용 펫. 플러그인(훅·커맨드·상태표시줄)과 Tauri 위젯.

**Architecture:** 단일 진실 공급원 `~/.claude/pet/state.json`. 플러그인의 `petlib` 패키지만 쓰고(flock + atomic rename), 모든 진입점은 `store.transaction()`으로 열며 진입 시 지연 틱이 돈다. 로직은 전부 `now`를 인자로 받는 순수 함수라 pytest로 표 단위 검증. Tauri 앱은 파일 감시로 읽기만 하고 먹이주기는 `pet.py feed --json` 서브프로세스.

**Tech Stack:** Python 3.9+ 표준 라이브러리만, pytest. Tauri 2 + Rust(`notify`), 바닐라 HTML/CSS/JS.

설계 문서: `docs/superpowers/specs/2026-10-20-token-pet-v1-design.md` (이하 "설계"). 수치·표는 설계가 기준.

## Global Constraints

- Python 3.9 호환 (타입 힌트에 `list[str]` 대신 `List[str]` 또는 `from __future__ import annotations`). 외부 패키지 금지.
- 모든 시각은 timezone-aware `datetime`. 로컬 타임존은 `clock.local_tz()`. 저장은 `isoformat()`.
- `PET_HOME` 환경변수가 있으면 `~/.claude/pet` 대신 그 경로를 쓴다(테스트용).
- 훅 스크립트는 어떤 예외에도 exit 0, stdout 비움(SessionStart의 additionalContext 제외). 오류는 `PET_HOME/collect.log`에 append, 50줄 유지.
- 커밋 메시지는 한 줄 `type: 설명`.
- 테스트 실행: `cd plugin && python3 -m pytest -q`.
