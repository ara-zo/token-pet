# 세계관 · 토큰 마을

귀엽지만 뒤에 뭔가 깔려 있는 톤. 노동(토큰)으로 먹고사는 작은 생명체들. 타락은 병이 아니라 선택이다.

```
생각 공장 → 토큰 조각 → 토키 → 환전소
```

## 등장하는 것

- **토키**: 모찌 같은 작은 생명체. 토큰 마을에 산다.
- **생각 공장**: 사람이 Claude에게 뭔가 물을 때마다 돌아간다. 굴뚝에서 **토큰 조각**이 떨어진다.
- **환전소**: 조각을 코인으로 바꿔 준다. 환율은 환전소가 정한다. 공장이 만들어 낸 조각(출력)만 받고, 읽기만 한 조각(입력·캐시)은 안 받는다. 재활용 조각은 소액 포상(캐시 적중 보너스). 하루에 받는 양에도 한도가 있어서, 한도를 넘긴 조각은 헐값에 받는다(소프트캡).

사용자가 일하면 토키도 일한다. 주인이 쉬면 토키는 굶는다.

## 노동의 어두운 면

조각은 끝이 없고 환율은 토키가 못 정한다. 공장이 너무 돌면 마을에 **연기**가 깔린다(번아웃). "밤엔 조각이 두 배"라는 소문에 밤에 나가는 애들이 생기고(올빼미), 그러다 햇빛을 못 견디게 된다(흡혈귀).

## 타락은 병이 아니라 선택

배고픈 채 방치된 토키는 환전소 뒷골목에서 **남의 코인 가져오는 법**을 배운다. 불량배는 주인을 미워하지 않는다. "안 주니까 내가 가져가야지." 매일 잔액 10%를 가져가며 말한다. 이건 내 몫이야. 3일 먹이면 돌아오는 건, 미움이 아니라 배고픔이었기 때문이다.

## 가출

7일 동안 아무도 안 오면 "이 공장은 멈췄구나" 하고 코인 절반을 들고 **다른 마을의 공장**을 찾아 떠난다. `/pet find`가 서로 다른 날 3번인 건, 소문을 따라 세 마을을 돌아야 하기 때문이다. 찾아오면 그 마을에서 본 무언가를 기억해 온다.

## 환전소 자격시험 (진화)

Lv.5·Lv.10에 "지난 7일 이렇게 살았네요" 결과지가 나온다. 합격/불합격이 아니라 **배정**이다. "당신의 토키는 ○○ 과정에 배정되었습니다." 게이지는 안 보여 준다.

## 말풍선 톤

짧고, 귀엽고, 가끔 한 줄이 서늘하게. 형태 16개 × 상황(평소·배고픔·심심·밥·쓰다듬기·획득·거절·구매·밤) 전문은 [`plugin/scripts/petlib/speech_lines.py`](../plugin/scripts/petlib/speech_lines.py).

| 상황 | 예 |
|---|---|
| 평소 | 오늘도 공장 돌아간다~ · 조각 주웠다! 반짝반짝 |
| 배고플 때 | 환전소 아저씨가 외상은 안 된대… · 옆집 토키는 오늘 세 번 먹었대. |
| 불량배 | 야. 10%는 내 거다. 토 달지 마라. · 상점? 닫았어. 내가 닫았어. |
| 조직 보스 | 이 상태표시줄, 오늘부터 우리 구역이야. · 어쩔 건데. 신고? 환전소가 우리 편인데. |
| 가출 직전 | 다른 마을엔 공장이 두 개래. |

| 배경 | 얻는 법 | 보너스 |
|---|---|---|
| 환전소 거리 | 기본 | 없음 |

| 환전소 금고 안 | 1,500코인 | 구두쇠·재벌이면 이자 +0.5%p |
| 환전소 뒷골목 | ??? | ??? |
| ??? | ??? | ??? |

이름(토키·생각 공장·환전소)은 바꿀 수 있다.
