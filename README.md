# Token Pet 🐣

> 사람이 Claude에게 뭔가 물을 때마다 토큰 마을의 생각 공장이 돌아가고, 굴뚝에서 토큰 조각이 떨어진다.
> 작은 생명체 토키는 그 조각을 주워 환전소에서 코인으로 바꿔 먹고산다.
> 주인이 일하면 토키도 일하고, 주인이 쉬면 토키는 굶는다. ([세계관](docs/LORE.md))

Claude Code에서 쓴 **출력 토큰이 코인**이 되는 다마고치. 코인으로 먹이를 주고 꾸미고, 어떻게 키웠느냐에 따라 **진화가 갈린다**. 서버도 계정도 없다. 전부 `~/.claude/pet/state.json` 하나에 저장된다.

```
~/work/dev-hub │ opus │ 🐣 모찌 Lv.3 🪙1,240 +12 배고픔▓▓░░░ 기분▓▓▓▓░ │ ctx 41% · $2.18
```

## 설치

Claude Code 안에서:

```
/plugin marketplace add ara-zo/token-pet
/plugin install token-pet@token-pet
```

새 세션을 시작하면 펫이 태어난다. 상태표시줄에 띄우려면 한 번 더:

```
/token-pet:pet setup
```

플러그인 명령에는 플러그인 이름이 붙어서 실제 명령은 `/token-pet:pet` 이다. 아래 표에서는 `/pet` 으로 줄여 쓴다.

요구사항: macOS, `python3` (Command Line Tools에 포함). Windows는 아직 지원하지 않는다.

### 업데이트

새 버전은 자동으로 오지 않는다. 받으려면:

```
/plugin marketplace update token-pet
```

자동으로 받으려면 `/plugin` → Marketplaces → token-pet → **Enable auto-update**.

## 사용법

| 명령 | 설명 |
|---|---|
| `/pet` | 상태 (레벨·코인·배고픔·기분·말풍선·진화 예감) |
| `/pet feed` | 먹이주기. 50코인 → 배고픔 +40 |
| `/pet pat` | 쓰다듬기. 기분 +8, 하루 5번 |
| `/pet stats` | 최근 7일 코인·출력 토큰·먹이 기록 |
| `/pet dex` | 토키 도감: 만난 토키, 아직 못 만난 토키의 기척, 쉬는 펫 |
| `/pet adopt <종족> [이름]` | 도감에 등록된 종족 입양 (입양비) |
| `/pet switch <종족>` | 쉬고 있는 펫을 데려와 돌보기 |
| `/pet shop` | 상점 목록과 가격 |
| `/pet buy <id>` | 구매 (`fedora`, `sunglasses`, `hoodie`, `cushion`, `plant`, `crown`, 배경 `night_factory`, `vault`) |
| `/pet equip <id>` / `unequip <slot>` | 착용·해제 (슬롯: head, face, body, room, bg) |
| `/pet name <이름>` | 이름 바꾸기 (1~8자) |
| `/pet find` | 가출했을 때 찾기. 서로 다른 날 3번 |
| `/pet reset --confirm` | 지금 돌보는 펫만 새로 시작 (코인·옷장·도감·쉬는 펫은 유지) |
| `/pet pr on` / `off` | 위젯에 내 리뷰를 기다리는 PR 알림 켜기·끄기 (gh 로그인 필요. 기본은 꺼짐) |
| `/pet setup` | 상태표시줄 설정 |
| `/pet widget [on\|off\|install\|update]` | 데스크톱 위젯 상태·자동 실행 켜고 끄기·설치·업데이트 |

## 규칙

- **코인**: 출력 1k 토큰 = 2코인. 하루 출력 300k를 넘긴 부분은 1k = 0.3코인(환전소 일일 한도). 서브에이전트가 쓴 출력도 포함. 캐시 적중률 50% 이상이면 +5%. 입력 토큰은 0.
- **배고픔** 시간당 -5, **기분** 시간당 -2 (배고픔 0이면 기분 -4). 세션을 안 켜도 시간은 간다.
- **레벨**: xp = 누적 획득 코인. Lv.5 = 10,000 / Lv.10 = 40,000.
- **진화**: Lv.5와 Lv.10에 한 번씩. 어떤 모습이 될지는 그동안 어떻게 키웠느냐(밥 주는 때, 일하는 시간, 코인 쓰는 버릇)로 갈린다. 어떤 갈래가 있는지는 키우면서 알아 가는 재미로 남겨 둔다. 다가오면 `/pet` 과 위젯에 **진화 예감**이 뜬다.
- 너무 오래 내버려 두면 펫에게 좋지 않은 일이 생긴다. 무슨 일인지는 펫이 말해 줄 것이다.

## 토키 도감

토큰 마을엔 모찌 말고도 여러 토키가 산다. 첫 펫은 항상 모찌이고, 평생 기록이 조건을 채우면 도감에 등록된다. 등록된 종족은 입양비를 내고 `/pet adopt` 로 데려온다. 여러 마리를 키울 수 있고, 한 번에 한 마리를 돌본다. 나머지는 마을에서 쉬며 배고픔·기분·경험치가 멈춘 채 기다린다. `/pet switch` 로 데려온다. 코인·옷장·도감은 모두가 함께 쓰고, 레벨·진화·착용은 펫마다 따로다.

도감에서 잠긴 종족은 이름 대신 `???`, 조건 대신 소문 한 줄과 기척(●○○ 아직 조용함 → ●●○ 기척이 느껴짐 → ●●● 곧 만날 것 같음)만 보인다. 기척이 마지막 단계가 되면 한 번 알려 주고, 등록되면 그제야 만난 계기를 알려 준다.

몇 종족이 사는지, 무엇을 하면 만나는지는 비밀. `/pet dex` 의 소문과 기척을 따라가 보자. 진화하면 종족마다 고유한 부위도 함께 변한다.

## 데스크톱 위젯

`app/`의 Tauri 앱은 화면 구석에 펫을 띄운다. 플러그인을 설치하고 첫 세션을 시작하면 GitHub Releases에서 위젯을 받아 `~/Applications`에 설치하고 바로 띄운다(백그라운드, 하루 한 번까지 재시도). 그 뒤로는 로그인할 때와 Claude Code 세션을 시작할 때 저절로 뜬다. 하루 한 번 새 릴리스가 있는지 보고 있으면 그 자리에서 바꿔 끼운다. 끄려면 `/pet widget off`, 직접 설치하려면 `/pet widget install`, 바로 업데이트하려면 `/pet widget update`. 접힌 상태 120×120, 클릭하면 펼쳐져 먹이를 주고 상점에서 꾸밀 수 있다. 플러그인이 쓰는 `state.json`을 감시해서 읽기만 하고, 먹이주기·구매·착용은 플러그인 스크립트를 호출한다. 빌드는 `app/README.md` 참고. 없어도 플러그인만으로 전부 동작한다.

## 구조

```
.claude-plugin/marketplace.json   레포 자체가 마켓플레이스
plugin/
  hooks/hooks.json                Stop → collect.py (코인 적립), SessionStart → tick.py (시간 정산·알림)
  skills/pet/SKILL.md             /pet (정식 이름은 /token-pet:pet)
  scripts/petlib/                 모든 로직. 순수 함수 + pytest (plugin/tests)
app/                              Tauri 2 위젯
docs/                             컨셉 스펙, 목업, 설계·플랜 (진화·도감 조건이 다 적혀 있어요. 스포일러 주의)
```

- 상태 파일 쓰기는 `petlib`만 한다. `flock` 잠금 + 임시파일 rename이라 세션 여러 개가 동시에 돌아도 안전하다.
- 트랜스크립트는 바이트 오프셋 + `message.id` 중복 제거로 증분 집계한다 (한 응답이 여러 줄로 저장되고, Stop 시점에 마지막 줄이 아직 없을 수 있어서).
- 서브에이전트 토큰은 1차에서 세지 않는다.

테스트: `cd plugin && python3 -m pytest -q`

## 아직 안 정한 것

- 환율·소프트캡·감소 속도·레벨 구간은 경제 밸런스 v2 추정값. `daily_log.tokens_out` 2주치로 재조정
- 상점 아이템이 적어서 아이템 수를 보는 진화 기준을 스펙보다 낮춰 뒀다. 아이템이 늘면 올린다
- 일부 진화 형태의 특수 보상, 앱 내 옷장, Windows, 코드 서명
